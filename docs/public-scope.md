# 公開範囲

個人運用の環境から、過去のGit履歴を引き継がずにソースを切り出しています。

| 含めるもの | 含めないもの |
| --- | --- |
| companion本体、テスト、運用スクリプト | 記憶DB、会話、プロフィール、ログ、バックアップ |
| 連携プラグインと設定の例 | .env、本番のHermes設定、個人名、PC固有のパス |
| 汎用の人格・プロンプト | 個人運用の人格原文、手紙、自己メモ |
| 公開向けに書き直した文書 | 応募メモ、作業用ファイル、調査用の第三者ソース・取得資料 |

プラグインの著者表示はGitHubの公開名へそろえ、固定パスと個人の好みが入る使用例を一般化しています。元の運用環境は別に保持します。

秘密情報の検出テストにある認証値らしい文字列は、伏字処理を試す合成データです。実際の認証情報を含めることは認めていません。

追加するスクリーンショットや動画は、テスト用の会話・人格・記憶で撮影します。未撮影の画面や未測定の効果はREADMEに掲載していません。
